**실기기 점검표** (iPhone Safari, Galaxy 삼성 인터넷)

1. 처음 화면에서 '들여다보기' → 그래프가 그려지는가
2. 날짜 칸을 누르면 달력이 열리고, 고른 날짜가 `2026.04.05 (일)` 형식으로 보이는가
3. 그래프를 누르거나 슬라이더를 끌면 시간이 바뀌고, 페이지 스크롤이 막히지 않는가
4. 단서 창이 열리고, 창 안이 스크롤되며, ✕로 닫히는가
5. 하단 탭이 홈 표시줄·주소창과 겹치지 않는가
6. 공유한 주소로 바로 열리고, 뒤로 가기가 이전 역·날짜로 돌아가는가
7. 처음 데이터를 여는 시간이 체감상 괜찮은가
